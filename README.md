# tymek.me

My personal website built with Zola and the Serene theme.

## Features

- Blog posts
- Projects showcase
- About page with experience
- Dark/light mode support
- RSS feed

## Development

### Prerequisites

- [Zola](https://www.getzola.org/) - `brew install zola`
- The Serene theme (Git submodule)

### Running locally

```bash
zola serve
```
## Built with

- [Zola](https://www.getzola.org/) - Static site generator
- [Serene theme](https://github.com/isunjn/serene) - Clean, minimalist theme
